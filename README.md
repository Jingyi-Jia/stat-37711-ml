# STAT 37711 Machine Learning: homework

Each homework lives in its own folder: `homework_1`, `homework_2`, and so on.

Completed homework folders contain code that runs after a fresh clone. Each has its own `README.md` that gives:

- the dependencies (and a `requirements.txt` where needed),
- the exact command to run,
- the outputs the command writes.

## Quick start

```bash
git clone https://github.com/Jingyi-Jia/stat-37711-ml.git
cd stat-37711-ml/homework_N
pip install -r requirements.txt   # if the folder has one
```

Then follow `homework_N/README.md`.

`homework_1/` contains the executed notebook, its PDF export, and the local ALE dataset.
